# TLM Labs

Research, open-source tools and AI datasets for blockchains and DeFi markets.

## Projects

- **[TLM Research](https://github.com/TLM-Research)**: an open research program on temporal liquidity, the value of when and in what order a transaction executes, and the fee markets that could price it. Ethereum is the first platform.
- **[TEMBRI](https://github.com/TLMlabs/tembri)**: an open-source Rust toolbox for measuring Ethereum execution: mempool arrival, block builders, and PropAMM updates and fills.
- **[QuantFeatures AI](https://github.com/QuantFeatures)**: interval-based crypto market features computed from tick data, at intervals from 30 seconds to 3 hours, with free samples on [Hugging Face](https://huggingface.co/QuantFeatures).
